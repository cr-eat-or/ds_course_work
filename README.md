# Курсовая работа — «Жизнь» (Game of Life)

Реализация на **C11**: два буфера поля, пошаговая эволюция по правилам Конвея, учёт **циклов** в истории конфигураций, **шаблоны** (статические паттерны), консольный интерфейс с отрисовкой поля (UTF-8, рамки Box Drawing). Точка входа — **`src/main.c`** (интерактивный ввод с клавиатуры); ядро симуляции и тесты не зависят от консоли.

## Схема каталогов

| Каталог | Назначение |
| ------- | ---------- |
| `include/` | Заголовки: `grid.h`, `life.h`, `cycle.h`, `templates.h`. |
| `src/` | Реализация сетки, шага «Жизни», обнаружения циклов, шаблонов и `main.c` (консоль). |
| `tests/unit/` | Юнит-тесты модулей; общая точка входа — `test_main.c`. |
| `tests/include/` | Вспомогательные заголовки для тестов (`test_helpers.h`). |
| `build/` | Собранные исполняемые файлы после `make` (не коммитить). |
| `.vscode/` | `launch.json` и `tasks.json` для отладки в VS Code / Cursor (**GDB**, задача `make (debug)`). |

## Сборка

Нужны **GCC** и **GNU Make**.

```sh
make all       # main.exe и test.exe
make test      # только пересобрать test.exe (если менялись тесты)
make clean     # удалить каталог build/ 
```

**Отладочная сборка** (символы для GDB: `-g`, без оптимизаций: `-O0`):

```sh
make clean
make DEBUG=1 all
```

Без `DEBUG=1` эти флаги к `CFLAGS` не добавляются (см. верх `Makefile`).

### VS Code / Cursor

В **`.vscode/`**:

- **`tasks.json`** — задачи **`make (debug)`** (`DEBUG=1 all`) и **`make (clean)`**; задача сборки по умолчанию — отладочная.
- **`launch.json`** — конфигурации **`ds_course_work (main)`** и **`test.exe (unit tests)`** с `preLaunchTask: make (debug)` и **gdb**.

Запуск: панель **Run and Debug**, выбор конфигурации, **F5**.

| Цель `make` | Исполняемый файл |
| ----------- | ---------------- |
| `all` | `build/main.exe` |
| `all` | `build/test.exe` |

## Запуск программы

Интерактивный режим (аргументы командной строки не используются):

```sh
./build/main.exe
```

Консоль желательно перевести в **UTF-8** (корректное отображение рамки и символов клеток `██` / `[]`). Размер поля по умолчанию задаётся в `main.c` константами **`WIDTH`** и **`HEIGHT`** (32×32).

### Команды в сеансе

После запуска ввод построчно из **stdin** (краткая справка в программе — **`?`**):

| Ввод | Действие |
| ---- | -------- |
| **Enter** | одно поколение |
| **n** | то же (строка должна содержать только `n`) |
| **a** `N` `[мс]` | `N` поколений с паузой между кадрами (мс; по умолчанию 100; `0` — без паузы) |
| **z** `[мс]` | шагать, пока не будет обнаружен цикл (пауза между кадрами; верхний предел шагов задан в коде) |
| **1**–**9** | вставить шаблон **1..9** по центру поля |
| **t** `N` `c` `r` | шаблон `N` с якорем в клетке столбец `c`, строка `r` |
| **k** `x` `y` … | отметить живыми клетки парами «столбец строка» (индексы с 0) |
| **p** | перерисовать поле |
| **r** | новая партия (сброс поля) |
| **?** | полная справка по командам и именам шаблонов |
| **q** | выход |

Шаблоны: блок, мигалка, глайдер, крест, вселенная Кока, королевская пчела, жаба, маяк, R-пентомино (нумерация 1–9 — в выводе справки в программе).

## Тесты

```sh
make tests
./build/test.exe
```

При успехе в консоли: **`All tests passed.`**

## Makefile

Сборка **без промежуточных `.o`**: один вызов `gcc` на цель **`main.exe`** и один на **`test.exe`**. Списки исходников ядра и тестов заданы переменными **`CORE`** и **`TEST`** в `Makefile`. Флаг **`DEBUG=1`** добавляет к `CFLAGS` опции **`-g -O0`**.
